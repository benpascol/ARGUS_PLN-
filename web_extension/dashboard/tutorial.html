01

Persiapan Berkas & Impor Data (Foto + Rekap ACMT)

Mendukung unggah massal ribuan foto dengan proteksi anti-duplikasi otomatis

Lokasi Folder Penyimpanan Resmi

  • data\input_foto\ — Tempat menyimpan folder foto dokumentasi LBKB (JPG/PNG).
  • data\input_excel\ — Tempat menyimpan berkas rekap Excel ACMT (.xlsx / .csv).
  • data\audit_results\ — Direktori cadangan hasil audit lokal.
  • Catatan penting: Jangan tutup jendela terminal hitam CMD selama aplikasi berjalan; untuk menutup aplikasi dengan aman tekan Ctrl+C.

Urutan Unggah di Dashboard

  1. (Disarankan lebih dulu) Impor Rekap ACMT: Klik tombol hijau Impor Rekap ACMT (.xlsx / .csv) agar sistem mengindeks IDPEL, Nama Pelanggan, Tarif/Daya, dan Stan Lapangan.
  2. Unggah Folder Foto: Klik Unggah Folder Foto (atau seret langsung folder/file ke area tengah tabel).
  3. Proteksi Duplikasi: Jika ada foto yang sama dengan antrean, modal pilihan Lewati Duplikat (Skip) atau Timpa (Overwrite) otomatis muncul.
02

Memilih Mode Audit & Menjalankan Batch AI

Fleksibel untuk audit perbandingan Excel ACMT maupun ekstraksi angka murni tanpa Excel

3 Pilihan Mode di Toolbar

  • Auto (Sesuai Data): Direkomendasikan. Jika baris memiliki Stan Lapangan dari ACMT, sistem membandingkan selisihnya; jika kosong, sistem tetap mengekstrak angka meteran tanpa vonis beda stand palsu.
  • Ekstraksi Mandiri (Murni AI): Khusus saat tidak membawa rekap Excel ACMT. Fokus membaca angka valid, mendeteksi blur/glare, dan menyaring foto non-meteran.
  • Komparasi ACMT Lapangan: Wajib membandingkan bacaan AI dengan Stan Lapangan pada setiap baris.

Eksekusi Batch & Perlindungan Koreksi

  • Klik tombol hijau Mulai Audit Batch. Progress bar dan estimasi waktu selesai (ETA) akan berjalan real-time.
  • Server otomatis mendeteksi perangkat (GPU RTX / CPU) dan mengatur jumlah Worker paralel secara optimal.
  • Aman saat audit ulang: Baris yang sudah Anda koreksi manual (berlabel Dikoreksi) tidak akan ditimpa apabila tombol batch ditekan lagi.
03

Memahami 7 Kartu KPI, Quick Sort & Pencarian Cepat

Warna di bawah mencerminkan kartu filter asli di Dashboard — klik kartu mana saja untuk menyaring tabel
Total Sampel (ALL) Menampilkan seluruh foto dalam antrean sesi aktif.
Sesuai Match Stan baca AI presisi sama dengan Stan Lapangan (Selisih = 0 kWh).
Rolling Digit Selisih tipis ±1 s.d. ±2 kWh akibat drum angka meter analog sedang berputar transisi.
Beda Stand Selisih > 2 kWh — prioritas utama untuk diverifikasi auditor di Modal Pratinjau.
Perlu Tinjau Ulang (TRIAGE) Foto buram parah, silau matahari (glare), atau angka terpotong/ambigu sehingga butuh mata auditor.
Bukan KWH / Nihil Foto non-meteran (pagar terkunci, aspal, jok motor, dinding) — tidak ditemukan dial meteran.
Dikoreksi Auditor Menyaring semua baris yang telah diedit manual atau diberi Catatan Evaluasi Model AI.
Tips Sortir & Pencarian: Klik judul kolom bertanda panah (NO, IDPEL, NAMA, STAN LAPANGAN, SELISIH (kWh), VONIS AUDIT, LATENSI) untuk mengurutkan anomali terbesar ke paling atas. Gunakan kotak Cari IDPEL / Nama dan pengatur Baris per halaman (25 / 50 / 100 / Semua) di bawah tabel.

Pemisahan Catatan PLN vs Catatan AI & Smart Un-Edit

  • Catatan Auditor (Laporan Excel PLN): Untuk catatan operasional dinas (mis. "Rumah tutup"). Ikut masuk ke file Excel resmi PLN dan tidak memicu label Dikoreksi.
  • Catatan Evaluasi Model AI (Celengan 1.000): Khusus evaluasi salah baca model agar AI makin pintar. Klik tombol tag cepat (Salah Baca Angka, Digit Terpotong, Rolling Meleset) untuk pasang/lepas tag, atau ikon × untuk membersihkan.
  • Smart Baseline Un-Edit: Jika angka & vonis Anda kembalikan persis ke hasil asli ARGUS dan Catatan AI kosong, label Dikoreksi otomatis terhapus dan antrean Celengan AI ikut dibersihkan.

Celengan Feedback AI Persisten (Target 1.000 Kasus)

Tersimpan aman di profil Windows (%LOCALAPPDATA%) sehingga kebal dari repack maupun upgrade versi aplikasi

Lokasi Aman & Anti-Hilang

  • Setiap baris yang Dikoreksi atau memiliki Catatan AI otomatis tersimpan ke direktori sistem lokal %LOCALAPPDATA%\ARGUS_PLN\feedback_vault\ (subfolder staging\ dan releases\), lengkap dengan foto asli, potongan dial, & pre-label YOLO.
  • Kebal Repack & Upgrade: Karena terpisah dari folder instalasi ARGUS.exe, tabungan tetap utuh meski browser di-Refresh (F5), tombol Reset Tabel diklik, aplikasi di-repack ulang, ataupun folder ARGUS diperbarui ke versi baru.
  • Anti-Duplikasi: Dikunci berdasarkan pasangan IDPEL + Nama File, sehingga mengedit ulang baris yang sama hanya memperbarui entri tersebut.

Akses Cepat Folder & Rilis ZIP (Untuk Petugas & Tim IT)

  • Lihat progres kapan saja pada kartu mini CELENGAN AI di pojok kanan atas header.
  • Klik kartu CELENGAN AI tersebut untuk membuka jendela pengelola: tersedia jalur folder lengkap, progress bar, daftar file .zip siap unduh, tombol Buka Folder Celengan (langsung membuka %LOCALAPPDATA%\ARGUS_PLN\feedback_vault\ di File Explorer tanpa perlu mencari manual), dan tombol Kemas Paket Sekarang (untuk tim IT/Engineer).
  • Saat mencapai 1.000 kasus unik, sistem otomatis membungkus 1 paket ARGUS_AI_Feedback_Batch_XX.zip ke subfolder releases\ dan mereset hitungan staging ke 0 / 1000.

Ekspor Laporan Resmi Excel & Solusi Kendala Umum

Format laporan standar PT PLN (Persero) UP3 Mojokerto beserta penanganan cepat

Unduh Laporan Excel Resmi (.xlsx)

  • Klik Unduh Laporan Excel Resmi (.xlsx) setelah audit selesai.
  • File berisi 4 baris header/legenda eksekutif, 19 kolom data audit lengkap, serta formula aktif =HYPERLINK(...) menuju foto asli dan hasil crop AI.
  • Catatan Model AI tidak dicampurkan ke file laporan dinas PLN ini agar laporan tetap bersih untuk kebutuhan operasional UP3 Mojokerto.

Troubleshooting Cepat

  • Aplikasi tampak berhenti di CMD: Pastikan tidak sengaja mengklik di dalam kotak hitam CMD (mode blokir seleksi sudah dinonaktifkan otomatis di V5, tekan Esc jika terlanjur menyorot teks).
  • Halaman tidak mau memuat di browser: Pastikan jendela terminal ARGUS.exe masih terbuka dan alamat di browser adalah http://127.0.0.1:8000/dashboard.
  • Layar kecil / baris terasa penuh: Atur Baris per halaman ke 25 atau 50, dan gunakan zoom browser 90% bila membuka di layar laptop 14 inci.
